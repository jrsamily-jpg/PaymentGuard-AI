# Synthetic data artifacts
`raw/` is reserved for explicitly confirmed synthetic CSV imports; no real payment or identity data is allowed. `processed/transactions.csv` contains the generated, validated and scored cohort; `processed/paymentguard.db` is the default SQLite store; `processed/results.json` records actual model evaluation and metadata. `case_study_simulation.json` records the exploratory scenario. Large data files and local DBs are ignored by Git and excluded from Docker build context. Reproduce them with `python -m scripts.ensure_data`.

Seed 42; 100,000 rows by default; fixed July–August 2026 UTC event window. All values are synthetic, all amounts are USD equivalents, IP addresses are in 192.0.2.0/24. Labels reflect generator scenarios and should never be treated as real investigative conclusions. Multiple profiles/contexts can vary per customer; upstream aggregate features are simulated rather than derived by replaying the ledger. See the data dictionary and model card.
